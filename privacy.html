سياسة الخصوصية — ImamKadem Event Tools

آخر تحديث: 27 نوفمبر 2026

ما هذه الأدوات

أدوات داخلية للفريق الإعلامي في مسجد الإمام الكاظم عليه السلام بالجارودية، تحدّث البث المباشر المجدول على قناة المسجد في يوتيوب.

البيانات التي تصل إليها

بعد إذن صاحب الحساب، تصل الأدوات عبر YouTube Data API إلى قناة المسجد وحدها: تقرأ بيانات البث المجدول، وتحدّث عنوانه ووصفه وموعده وحالته وصورته المصغرة. لا تصل إلى أي بيانات أخرى، ولا إلى بيانات أي مستخدم آخر.

التخزين

يُحفظ رمز الدخول (refresh token) في ملف على جهاز الفريق الإعلامي فقط، ولا يُرسل إلى أي خادم. ولا تجمع الأدوات أي بيانات شخصية ولا تخزنها.

المشاركة

لا تُشارك أي بيانات مع أي طرف ثالث، ولا تُستعمل للإعلانات أو لأي غرض غير تحديث بث قناة المسجد.

إلغاء الإذن

يمكن إلغاء إذن الأدوات في أي وقت من صفحة أذونات حساب Google: myaccount.google.com/permissions.

خدمات يوتيوب وGoogle

تستعمل الأدوات خدمات YouTube API. وباستعمالها تخضع لـ شروط خدمة يوتيوب، وسياسة خصوصية Google.

Privacy Policy — ImamKadem Event Tools

Last updated: November 27, 2026

What these tools are

Internal tools used by the media team of Imam Al-Kadhim Mosque, Al-Jarudiyah, to update the scheduled live broadcasts on the mosque's own YouTube channel.

Data accessed

With the account owner's consent, the tools use the YouTube Data API to access only the mosque's own channel: they read scheduled broadcast data and update a broadcast's title, description, scheduled start time, privacy status and thumbnail. They do not access any other data, or any other user's data.

Storage

The OAuth refresh token is stored only in a local file on the media team's own computer and is never sent to any server. The tools do not collect or store personal data.

Sharing

No data is shared with any third party or used for advertising or for any purpose other than updating the mosque's own broadcasts. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. Google's security settings page also lists it: security.google.com/settings/security/permissions.

YouTube and Google services

These tools use YouTube API Services. By using them you are bound by the YouTube Terms of Service, and the Google Privacy Policy applies.
